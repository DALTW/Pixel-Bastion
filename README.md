# GAME-3

## Pixel Bastion

**작은 영웅들이 지키는 최후의 요새.**

Pixel Bastion은 Unity 6로 제작한 2D 픽셀 아트 횡스크롤 디펜스 게임입니다. 플레이어는 골드를 사용해 다양한 Human 유닛을 소환하고, 오른쪽에서 끊임없이 몰려오는 Monster로부터 왼쪽의 타워를 방어해야 합니다.

검과 창을 사용하는 근거리 유닛, 화살과 마법을 사용하는 원거리 유닛을 전략적으로 조합하세요. 시간이 지날수록 더 강한 Monster가 등장하며, Human이 적을 처치하면 Monster 레벨에 따른 골드를 획득할 수 있습니다. 획득한 골드로 새로운 유닛을 소환해 최후의 요새를 지켜내는 것이 목표입니다.

### 핵심 특징

- 4개 구간으로 이어지는 횡스크롤 전장
- Human 9종과 Monster 11종의 자동 전투
- 근거리 공격과 실제 투사체 기반 원거리 공격
- 캐릭터별 이동·공격 애니메이션
- 골드를 사용하는 유닛 선택 및 소환 시스템
- 시간이 지날수록 강해지는 Monster 웨이브
- Monster 레벨에 비례하는 처치 보상
- 타워 체력, 패배 화면 및 재시작 기능
- 마우스 드래그를 이용한 전장 카메라 이동

### 플레이 흐름

1. 화면 아래의 캐릭터 카드에서 Human을 선택합니다.
2. 골드를 사용해 선택한 Human을 타워에서 소환합니다.
3. Human은 오른쪽으로 전진하며 Monster와 자동으로 전투합니다.
4. Monster를 처치해 골드를 획득하고 새로운 Human을 소환합니다.
5. 강해지는 웨이브를 막고 타워가 파괴되지 않도록 방어합니다.

### 실행 방법

1. Unity Hub에서 저장소 폴더를 추가합니다.
2. Unity `6000.5.4f1`로 프로젝트를 엽니다.
3. `Assets/Scenes/SideDefense.unity` 씬을 엽니다.
4. Play 버튼을 눌러 게임을 실행합니다.

자세한 제작 기록은 [`Docs/DevelopmentLog_2026-07-26.md`](Docs/DevelopmentLog_2026-07-26.md), 게임 소개는 [`Docs/PixelBastion_Introduction.md`](Docs/PixelBastion_Introduction.md)에서 확인할 수 있습니다.

## 이전 프로토타입: Sunnyside 포획 게임

Unity 6로 제작한 Sunnyside 스타일의 탑다운 2D 포획 게임입니다. 야생동물을 비살상 방식으로 제압하고 고기·가죽·양털·깃털을 채취해 판매한 뒤, 캐릭터 능력과 사냥개를 강화할 수 있습니다.

### 개발 환경

- Unity `6000.5.4f1`
- Universal Render Pipeline (2D)
- Input System

### 프로젝트 열기

1. Unity Hub에서 이 저장소 폴더를 추가합니다.
2. Unity `6000.5.4f1`로 프로젝트를 엽니다.
3. `GAME-3 > Hunting Game Setup` 창에서 아트와 밸런스 설정을 확인하거나 수정합니다.
4. `Apply Import Settings`와 `Rebuild Scene`을 실행합니다.
5. `Assets/Scenes/HuntingGame.unity` 씬을 실행합니다.

설정에 누락된 에셋이나 잘못된 값이 있으면 Play 진입이 차단되고 Setup 창에 오류가 표시됩니다.

### 조작법

- 이동: `WASD` 또는 방향키
- 바라보는 방향으로 제압 공격: `Space`
- 제압한 동물 채취 및 상점 이용: `E` 길게 누르기
- 상점 닫기: `Esc`

들새·닭·오리·양은 플레이어를 피해 도망가고, 멧돼지와 소는 확률적으로 반격합니다. 동물을 제압한 뒤 전리품을 채취하고 캠프 상점에서 판매할 수 있습니다. 판매 수익으로 제압력·이동 속도·최대 체력을 영구 강화하거나 사냥개를 구입할 수 있습니다.

기존 저장 파일은 v2로 자동 이전됩니다. 보유 돈과 사냥개는 유지되며, 더 이상 사용하지 않는 총기와 탄약 데이터는 제거됩니다.

`Library`, `Temp`, `Logs`, `UserSettings` 등의 로컬 생성 파일은 Git에서 제외됩니다.
