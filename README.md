# GAME-3

Unity 6로 제작한 탑다운 2D 헌팅 게임입니다. 동물을 사냥하고 고기와 가죽을 채취해 판매한 뒤, 더 좋은 무기와 사냥개를 구입할 수 있습니다.

## 개발 환경

- Unity `6000.5.4f1`
- Universal Render Pipeline (2D)
- Input System

## 프로젝트 열기

1. Unity Hub에서 이 저장소 폴더를 추가합니다.
2. Unity `6000.5.4f1`로 프로젝트를 엽니다.
3. `Assets/Scenes/HuntingGame.unity` 씬을 실행합니다.

## 조작법

- 이동: `WASD`
- 조준: 마우스
- 발사: 마우스 왼쪽 버튼
- 재장전: `R`
- 채취 및 상점 이용: `E` 길게 누르기
- 무기 선택: 숫자키 `1`~`4`

캠프 안에서는 사냥한 고기와 가죽을 판매하고 무기, 탄약, 사냥개를 구입할 수 있습니다. 게임 진행 상황은 자동으로 저장됩니다.

`Library`, `Temp`, `Logs`, `UserSettings` 등의 로컬 생성 파일은 Git에서 제외됩니다.
