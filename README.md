# GAME-3

Unity 6로 제작한 Sunnyside 스타일의 탑다운 2D 포획 게임입니다. 야생동물을 비살상 방식으로 제압하고 고기·가죽·양털·깃털을 채취해 판매한 뒤, 캐릭터 능력과 사냥개를 강화할 수 있습니다.

## 개발 환경

- Unity `6000.5.4f1`
- Universal Render Pipeline (2D)
- Input System

## 프로젝트 열기

1. Unity Hub에서 이 저장소 폴더를 추가합니다.
2. Unity `6000.5.4f1`로 프로젝트를 엽니다.
3. `GAME-3 > Hunting Game Setup` 창에서 아트와 밸런스 설정을 확인하거나 수정합니다.
4. `Apply Import Settings`와 `Rebuild Scene`을 실행합니다.
5. `Assets/Scenes/HuntingGame.unity` 씬을 실행합니다.

설정에 누락된 에셋이나 잘못된 값이 있으면 Play 진입이 차단되고 Setup 창에 오류가 표시됩니다.

## 조작법

- 이동: `WASD` 또는 방향키
- 바라보는 방향으로 제압 공격: `Space`
- 제압한 동물 채취 및 상점 이용: `E` 길게 누르기
- 상점 닫기: `Esc`

들새·닭·오리·양은 플레이어를 피해 도망가고, 멧돼지와 소는 확률적으로 반격합니다. 동물을 제압한 뒤 전리품을 채취하고 캠프 상점에서 판매할 수 있습니다. 판매 수익으로 제압력·이동 속도·최대 체력을 영구 강화하거나 사냥개를 구입할 수 있습니다.

기존 저장 파일은 v2로 자동 이전됩니다. 보유 돈과 사냥개는 유지되며, 더 이상 사용하지 않는 총기와 탄약 데이터는 제거됩니다.

`Library`, `Temp`, `Logs`, `UserSettings` 등의 로컬 생성 파일은 Git에서 제외됩니다.
